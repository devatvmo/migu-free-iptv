# migu-free-iptv

基于 GitHub + CNB 的咪咕直播频道采集与订阅生成项目。当前阶段只生成静态文件，不需要常驻服务器、Docker 或自有域名。

## 当前目标：中央1至13台

当前生成流程暂时不做免费/会员识别，只从咪咕频道目录中筛选中央1至中央13台，逐个请求游客模式播放接口，并生成候选 M3U 文件，供电视盒子逐台测试。

- 只处理中央1—13台，不再对其他分类频道请求播放地址。
- 暂不根据免费/会员属性过滤频道。
- 使用游客模式请求，使用旧版游客高清签名（`AppVersion=2600034600`）请求 `rateType=3`；按现有协议补充 `ddCalcu`、`sv=10004`、`ct=android`。协议可能变化，需持续复核。
- 保留咪咕原始调度地址，不在 CNB 端请求调度跳转、M3U8 或媒体分片；让最终播放器从自身网络访问调度地址。

## 重要：生成不等于播放验证

CNB 运行环境与最终电视盒子的网络环境不同。此前 CNB 请求咪咕调度地址遇到 HTTP 661，因此默认生成流程不再由 CNB 追踪调度跳转，也不再从 CNB 请求 M3U8 和媒体分片。

因此：

- `dispatch=true`：咪咕播放接口返回了原始游客调度地址。
- `playback_verified_count` 固定为 0；必须在电视盒子/播放器上逐台验证。
- 生成的 M3U 是待实测候选源，不代表已经能播放；播放器必须支持访问咪咕调度地址并跟随 HTTP(S) 重定向。

## 本地运行

需要 Go 1.22+：

```bash
go run ./cmd/migu-free-iptv -out ./dist
```

可选参数：`-categories`、`-out`、`-delay`。默认每个目标频道间隔 1.2 秒。

## 输出文件

- `dist/cctv-1-13.m3u`：中央1—13台候选直播源，供播放器导入。
- `dist/cctv-probe-report.json`：每个中央台的调度地址获取结果。
- `dist/candidates.json`：咪咕目录采集到的频道候选信息。
- `dist/summary.json`：本轮统计；明确区分获取调度地址与实际播放验证。

## 后续验证

先把 `cctv-1-13.m3u` 导入电视盒子，逐台测试能否播放。根据实测结果再处理失效地址、频道匹配和免费/会员识别；当前阶段不根据频道名称推断权益。

## 架构说明

CNB 负责运行采集与生成任务；GitHub 保存源代码和生成产物；GitHub Pages 后续可托管静态 M3U/TXT/JSON。咪咕播放地址可能短时有效，必须定期重新生成。Pages 本身不能在播放时动态换票。

本分支尚未配置 CNB 自动任务、GitHub 推送凭据或 Pages 发布，也尚未完成电视盒子端到端验证。
