# migu-free-iptv

基于 GitHub + CNB 的咪咕免费直播频道采集与订阅生成项目。当前阶段只生成静态文件，不需要常驻服务器、Docker 或自有域名。

## 当前版本

- 游客模式请求，不使用会员账号、Cookie 或会员 Token。
- 使用 `rateType=3` 请求免费高清档位（该参数与接口签名机制可能变化，需持续复核）。
- 采集 11 个频道分类，按 PID 去重。
- 串行检查游客播放地址、M3U8 与首个媒体分片。
- M3U/TXT 仅输出通过技术抽样且已列入人工免费确认名单的频道。
- 未配置免费确认名单时，订阅文件保持空白，这是有意的保守默认值。

## 本地运行

需要 Go 1.22+：

```bash
go run ./cmd/migu-free-iptv -out ./dist
```

可选参数：`-categories`、`-allowlist`、`-out`、`-delay`。默认每个频道间隔 1.2 秒，不建议降低请求间隔。

## 输出文件

- `dist/candidates.json`：采集到的候选频道目录。
- `dist/probe-report.json`：逐频道游客解析与播放抽样结果。
- `dist/free.m3u`、`dist/free.txt`：最终允许发布的频道。
- `dist/summary.json`：本轮统计。

## 免费频道确认规则

频道出现在目录中，或接口能返回 M3U8，都不能单独证明它无需会员。技术抽样成功也不等于完整连续播放验证。请先确认频道在游客状态下实际无需会员即可观看，再将 PID 添加到 `config/free_allowlist.json` 的 `pids` 数组。体育频道按具体节目/赛事权益判断，不按分类一刀切。

## 架构说明

CNB 负责定时运行采集与生成任务；GitHub 保存源代码和生成产物；GitHub Pages 后续只托管静态 M3U/TXT/JSON。咪咕播放地址可能短时有效，必须定期重新生成。Pages 本身不能在播放时动态换票。

本分支尚未配置 CNB 自动任务、GitHub 推送凭据或 Pages 发布，也尚未在 CNB 上执行端到端验证。
