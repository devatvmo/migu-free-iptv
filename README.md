# migu-free-iptv

基于 GitHub + CNB 的咪咕免费直播频道采集与订阅生成项目。当前阶段只生成静态文件，不需要常驻服务器、Docker 或自有域名。

## 当前版本

- 游客模式请求，不使用会员账号、Cookie 或会员 Token。
- 使用旧版游客高清签名（`AppVersion=2600034600`）请求 `rateType=3`；按社区实现补充 `ddCalcu`、`sv=10004`、`ct=android`。该协议可能变化，需持续复核。
- 保留咪咕原始调度地址，不在 CNB 端请求调度跳转、M3U8 或媒体分片；让最终播放器从自身网络访问调度地址。
- 采集 11 个频道分类，按 PID 去重。
- M3U/TXT 仅输出成功获取游客调度地址且已列入人工免费确认名单的频道。
- 未配置免费确认名单时，订阅文件保持空白，这是有意的保守默认值。

## 重要：生成不等于播放验证

CNB 运行环境与最终电视盒子的网络环境不同。此前 CNB 请求咪咕调度地址遇到 HTTP 661，因此默认生成流程不再由 CNB 追踪调度跳转，也不再从 CNB 请求 M3U8 和媒体分片。

因此：

- `resolved=true`：咪咕播放接口返回了原始游客调度地址。
- `publishable=true`：地址已获取，且 PID 在人工确认免费名单中。
- `playlist_ok`、`segment_ok`：默认流程不执行，保持 false。
- `playback_verified_count`：默认流程固定为 0；必须在中国大陆网络中的实际电视盒子/播放器上验证。

生成的 M3U 是待电视盒子实测的候选订阅。播放器必须支持访问咪咕调度地址并跟随 HTTP(S) 重定向；不同播放器的兼容性可能不同。不能仅凭文件生成成功就认定频道可播放，也不能保证所有电视盒子都支持该调度方式。

## 本地运行

需要 Go 1.22+：

```bash
go run ./cmd/migu-free-iptv -out ./dist
```

可选参数：`-categories`、`-allowlist`、`-out`、`-delay`。默认每个频道间隔 1.2 秒，不建议降低请求间隔。

## 输出文件

- `dist/candidates.json`：采集到的候选频道目录。
- `dist/probe-report.json`：逐频道游客调度地址获取结果及免费名单状态。
- `dist/free.m3u`、`dist/free.txt`：待电视盒子实测的候选订阅。
- `dist/summary.json`：本轮统计，明确区分生成数量与播放验证数量。

## 免费频道确认规则

频道出现在目录中，或接口能返回游客调度地址，都不能单独证明它无需会员。请先确认频道在游客状态下实际无需会员即可观看，再将 PID 添加到 `config/free_allowlist.json` 的 `pids` 数组。体育频道按具体节目/赛事权益判断，不按分类一刀切。会员频道不得加入名单。

## 架构说明

CNB 负责定时运行采集与生成任务；GitHub 保存源代码和生成产物；GitHub Pages 后续只托管静态 M3U/TXT/JSON。咪咕播放地址可能短时有效，必须定期重新生成。Pages 本身不能在播放时动态换票。

本分支尚未配置 CNB 自动任务、GitHub 推送凭据或 Pages 发布，也尚未在 CNB 和电视盒子上执行端到端验证。
